# The Deepanshi Experience ❤️

Free static website (HTML + CSS + JS). Koi server ya paid service nahi chahiye.

## Files
- `index.html`, `style.css`, `app.js`: website ka code
- `content.js`: **saara text + photos** (letter, notes, reasons, timeline, messages)

## Text / letter kaise badlein (sabse aasaan tareeka)
1. Site ko apne link ke aage `?edit` laga ke kholo, jaise `https://username.github.io/deepanshi/?edit`
2. Neeche **✏️ Edit** button dabao. Wahan har page ka text field me milega.
   - **Page 3: Letter**: apna letter paste/likho. Har paragraph ke beech ek khali line.
   - **Page 4: Photos**: 3-4 photos upload karo. Collage apne aap ban jata hai (Collage tab me, download bhi hota hai).
3. Jab ho jaye, **⬇ Export content.js** dabao. Ek nayi `content.js` file download hogi.
4. GitHub repo me purani `content.js` ko is nayi file se replace karo (Add file > Upload files). 1-2 minute me live site update ho jati hai.

Zaroori: edit mode ke badlaav sirf tumhare phone me draft hote hain. Deepanshi ko tabhi dikhenge jab nayi `content.js` GitHub par upload karoge. Photos bhi usi file ke andar hoti hain, isliye 10-12 se zyada mat daalo.

## Free deploy (GitHub Pages)
1. github.com par repo banao (jaise `deepanshi`), saari files upload karo.
2. Settings > Pages > Branch: `main` / root > Save.
3. Link milega: `https://<username>.github.io/deepanshi/`

## Feedback tumhe kaise milega (Formspree, free)
1. formspree.io par free account banao > New Form.
2. Wo link dega jaise `https://formspree.io/f/abcdwxyz`.
3. Edit mode > Page 9: Feedback > "Formspree link" me paste karo, phir Export + upload.
Jab tak ye set nahi hota, jawab sirf uske phone me save hota hai aur tumhe nahi milta (site usse ye bata bhi deti hai).

## Music
Copyrighted song download/upload nahi kiya gaya. Music button "03 Bonnie & Clyde" ke Spotify link ko kholta hai.
Agar tumhare paas song ki authorized audio file hai: usse repo me `music/song.mp3` naam se daalo aur Edit mode > Music me path `music/song.mp3` likho. Tab play/pause/mute site ke andar hi chalega (autoplay nahi hota).
